# UFG-1 — разбор гроссбуха / рейтингов

Источник: `refs/ufg1/data/ratings-dssd.xlsx` (лист **«Итоги»**; **«Лист2»** — посторонние формулы, к игре не относится).  
Машиночитаемый дамп: `refs/ufg1/data/ratings-parsed.json`.

## Модель строки игрока

| Поле | Смысл |
|------|--------|
| **Траты** | `=SUM` всех ячеек туров — главный рейтинг активности |
| **Номер в игре** | Метка 14–39 (в этой партии 25 игроков; №38 нет) |
| **Игрок** | Имя |
| **Команда глоб 1** | Метка места: **Белые** / **Красные** |
| **Команда глоб 2** | Вторая ось: **Синие** / **Стеклышки** |
| **Команда индивид.** | Призовая мини-команда: КМЛ, НРС, Миньоны, ЮХХ, ЛП (или пусто) |
| **1…7 тур** | Сколько золотых потратил в туре |

Формула рейтинга подтверждена: **траты = сумма ставок по турам**, не остаток в кошельке.

## Три оси команд (важно для «синих»)

1. **Метки (глоб 1)** — Белые (чёт) / Красные (нечёт) → ротация мест.  
2. **Департамент (глоб 2)** — **Синие** (16 чел., 159 золотых) / **Стеклышки** (9 чел., 87).  
3. **Индивид. команды** — для призов мини-групп.

Итого по меткам: Белые 12 / 115 золотых, Красные 13 / 131.

> В анонсе тура «красные / белые / **синие**» — «синие», скорее всего, = **Команда глоб 2**, а не цвет бирки. Уточнить у оргов, фильтровали ли выкладку карт ещё и по «Стеклышкам».

## Структура туров в таблице

| Тур | Ячейки | Как суммируется |
|-----|--------|-----------------|
| 1 | H | одна колонка |
| 2 | I | одна |
| 3 | J+K | две → агрегат V |
| 4 | L | одна |
| 5 | M+N | две → W |
| 6 | O+P | две → X |
| 7 | Q…U (пять) | → Y |

Несколько колонок в туре = несколько записей трат за тур (повторные ставки / несколько карт). В приложении: список транзакций на тур, не одно число.

## Что переносится в приложение
- Гроссбух = поток транзакций `{player, round, amount, type}`; **Траты** = sum(amount where type=spend).
- Займы учитывать отдельно (долг банку / реальные ₽), но в рейтинг «активности» из Excel, похоже, входят только **траты на ставки**.
- Рейтинги строить по осям: личка / метка / глоб2 / индивид. команда.
- Экспорт BBCode-таблицы в Excel (колонка AC) — для публикации в форум/VK; в приложении можно генерировать сразу.
