## Тур
- Тур = полный цикл: выложили карты → проголосовали (ставки) → разобрали выигрыш → карты в сброс.
- Целевое число туров в приложении: **10** (вживую было 7 из‑за времени).
- Таймер тура **15–20 мин**; если все, кто может, сделали ставки — тур закрывается **через 1 мин после последней ставки**.
- Смена мест в электронную версию **не обязательна** (опционально команда/напоминание на экране).
- Чередование **красных / белых** по турам (чёт/нечёт меток). ⚠️ уточнить: чередуются выкладка карт или ставки (или оба).
- **Синие / Стеклышки** = пьющие / непьющие; выбор в начале; только для рейтингов, не для фильтра тура.

## Пул правил
- Карточки правил **ещё генерировать**; текст/формат — открыт.
- Каждый тур **добавляется** правило; ранее добавленное **может измениться**.
- Действует, пока не отменят.
- Идея: рандомная тяга; риск конфликтов — решить позже, после сбора пула.
- Меняют/добавляют способы экономического взаимодействия.
- Пример из жизни: расширение векселя **3 → 5**.
- Отдельный UI «инструкция правила» пока не делаем (достаточно текста на карточке).

## Ситуация и карты
- Симбиоз **Imaginarium + мемология**: система **рандомно** выбирает карту ситуации; игрок подбирает карту из руки.
- На опыте ситуацию потом почти не смотрят — гонка ставить на «своих».
- Онлайн-флоу: игрок выбирает карту → отправка → когда все выбрали — **перемешивание** → выкладка лицом вверх.
- ⚠️ Фиксировать ли владельца карты до/во время голосования (командный сговор).
- Кто выкладывает в туре — по цвету метки (вживую была путаница, ушли на чёт/нечёт).
- Правилами можно ввести другое деление (напр. мальчики/девочки).
- Докупка карт из банка возможна; возврат в руку — зависит от объёма сгенерированной колоды.
- Стартовая рука: микс из 3 колод; вживую 9 карт хватило на 7 туров.

## Ставки и выплата
- Старт: **1 монета на 1 карту**.
- Правилами: до **3** на одну карту; затем на несколько карт, но **суммарно ≤ 3** за акт ставок (?).
- За свою карту нельзя; **кто выложил карту — не голосует**. ⚠️ возможно смягчим для динамики.
- **Каждый** владелец забирает кучу со своей карты (не один победитель).
- Победителю (⚠️ «бад» = **балл**?) засчитывается очко; при равных кучах — балл **каждому** из лидеров.
- Ликвидность сразу в оборот.
- Несколько ячеек в Excel = **разные виды сделок** — разобрать отдельно.

## Кошелёк и займы
- Старт: **1 монета** (+ вексель в котомке — из прошлых материалов).
- **Раз в тур** можно использовать вексель → займ в банке **целиком** в пределах лимита.
- На следующий тур можно **купить вексель** у игрока (цены бывали 1 / 3 / 5) и снова занять.
- Лимит займа растёт **карточкой правил** (3→5).
- Займ и досрочный возврат **не** в «Тратах».
- В конце: выкуп векселей у банка **по номиналу** оставшимися монетами; невыкупленные висят в профиле и влияют на допуск к следующим играм.
- Порог: долг **1000 ₽** → игра недоступна, пока не донат / погашение.
- Банкрот: может выкладывать карту в «свой» тур; займ у банка только с векселем; ⚠️ займ у игрока «раз в тур ≤ 3» — вживую P2P-долгов не было (п.40), для приложения — уточнить.

## Сделки
- Дарение запрещено; номера меток не меняются.
- Между игроками: **продажа карт** и **векселей** (когда правило открыто) + биржа / «предложение в личку».
- Вживую друг другу в долг не давали.

## Команды
- Синие/Стеклышки — самовыбор алкоголь/трезвость.
- Индив. команды: правило «команда из **3**»; капитан платит в казну **2**, участники по **1**; состав сразу трое или формирование не засчитывается.
- Без команды — отдельный зачёт.
- Командная гонка интереснее личной; глобальные рейтинги по сумме игр.
- Ведущий играл почти полноценно.
