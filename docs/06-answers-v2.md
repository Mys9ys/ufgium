## A. Противоречия — снято

| ID | Решение |
|----|---------|
| A1 | Тур 1: **белые выкладывают**, **красные ставят**. Дальше чередование сторон. |
| A2 | Ситуация = карточка мемологии («Когда ударился мизинцем…» / «Когда на тусе выходишь на балкон…»). |
| A3 | Балл ≠ траты. Балл — топ по куче; траты — всё из транзакций расходов; траты приоритетнее. |
| A4 | Первые туры: выложил → не голосует; потом **правило** может разрешить. |
| A5 | P2P-займ — **карточка правил** (см. пул). |
| A6 | 1 игровая монета займа = обещание **100 ₽**; играют занятыми; выкуп в конце монетами; нехватка → долг в профиле. |

## B. Тур

1. Обнародовать правило (в **1-м туре нет**).
2. Объявить, какая группа ходит картами.
3. Обнародовать ситуацию.  
   *(шаги 1–3 без пауз)*
4. **Блок сделок** — открыт до конца тура.
5. Выбор карт ходящей группой — **2–3 мин**; не успел → пас.
6. Публикация стенда (нумерация слотов).
7. Ставки (все, кому разрешено; кнопка паса + таймер).
8. Закрытие блока сделок.
9. Выплата владельцам + итог тура → сразу следующий тур.

- «Все ставки сделаны» = все, **кому разрешено голосовать**.
- Межтура как фазы нет; опционально **голосование за таймаут 10–15 мин**.
- Застолье: создатель может **закончить игру** досрочно → срез по сыгранным турам.

## C. Правила-мета

- Сначала собрать пул → потом формат карточки.
- Новое правило — **в начале тура**.
- Корректирующее правило правит предыдущее; **новое бьёт старое**.

## D. Стенд / сговор

- Открытые vs скрытые владельцы — **отложено** (после команд из 3 сильно голосуют за своих).
- Ставка в гроссбухе: на **номер слота** карты на стенде (`1…n`, сетка 2 ряда).
- Итог тура: карта + владелец + сколько получили.
- Бонуса «лучшая ассоциация» нет; экономика главное, «староверы» играют для себя.

## E. Ставки

- Цепочка 1→2→3 подтверждена; 2 и 3 — в таблице правил.
- Догонка ставки, пока тур не закончен, суммарно **≤ 3** (после соответствующих правил).
- Пас: кнопка + таймер.

## F. Вексель / ₽

- Займы у банка — **со 2-го тура**.
- UI долга — в процессе (флаг / цветная карточка).
- Продажа только **пустых** бланков.
- У банка: **1 бланк за тур** за 1 монету.
- Конец: гасишь сколько можешь монетами.
- Порог ~1000 ₽ пока ок; донат = виртуальные деньги → погашение / опции застолья.

## G. Команды из 3

- «Три мушкетёра»: инициатор зовёт → два accept → списание 2+1+1 → команда; платежи в **траты**.
- Монет в экономике **без потолка** (пока).
- Выход из команды не предусмотрен.
- Рейтинг команды = сумма трат троих.
- **Призы:** только индивид + команды из 3. Красные/белые и синие/стеклышки — для интереса/экранов без призового приоритета.

## H–K (кратко)

- Сделки: карты и векселя; ЛС или аукцион; только в блоке сделок.
- Рейтинги: все перечисленные доски; глобалка расширяемая; ступени блока по долгу — позже.
- Контент: плейсхолдеры без IP Imaginarium; ~**200** карт; гомункул — кандидат в маскот.
- Песочница тоже пишет долги; боевая — много комнат + бронь с дозаполнением; застолье мин. **4** + боты; удалённые гости — те же правила.
