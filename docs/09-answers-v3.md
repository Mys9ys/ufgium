## A. Тур

| ID | Решение |
|----|---------|
| A1 | Чередование подтверждено: T1 белые кладут / красные ставят → далее swap. При смене фильтра правилом — та же схема «группа A / группа B». |
| A2 | Пока тур **активен** — сделки разрешены (весь тур, параллельно фазам). |
| A3 | Онлайн-модель: всё в журнал; подтверждение ведущего **не нужно**. |
| A4 | На стенд попадают **все успевшие** из ходящей группы (без лимита «половина»). |
| A5 | Пас на выкладке → **карта не тратится**, остаётся в руке. |
| A6 | Таймер тура **15 мин** + кнопка **«Готов»**; если все нажали — тур может завершиться раньше. |

## B. Баллы и траты

| ID | Решение |
|----|---------|
| B1 | **Два** рейтинга баллов: (1) балл за **макс. кучу** на карте в туре; (2) **все ставки** = 1 монета → 1 балл. |
| B2 | Баллы — отдельная сущность, на **траты не влияют**. |
| B3 | Займы в тратах — уточним при реализации. |
| B4 | При покупке у игрока в **траты** идёт только **покупателю**. |

## C. Вексель / ₽

| ID | Решение |
|----|---------|
| C1 | **1 займ** и **1 покупка векселя** (банк или игрок) **за тур**. |
| C2 | `loan_limit_5`: только **новые** займы до 5; уже взятые — история, не пересчитываются. |
| C3 | Блок участия при долге **1000 ₽** (порог может вырасти). |
| C4 | Донат через VK; кошелёк — отдельная тема после MVP. |

## D. Команды

| ID | Решение |
|----|---------|
| D1 | Взнос 2+1+1 → **банк**; денежную массу не ограничиваем. |
| D2 | Создание команды — после карточки правила. |
| D3 | Капитан жмёт «создать», шлёт **>2** инвайтов; как только **2 приняли** — команда создаётся, остальные инвайты сгорают, списание монет. |
| D4 | Без команды можно получить инвайт позже; иначе только **личный** зачёт трат. |

## E. Стенд

| ID | Решение |
|----|---------|
| E1 | Пустые слоты **схлопываются** → нумерация 1…K плотная. |
| E2 | Скрытые владельцы — только **отдельным правилом** (по умолчанию открыто). |
| E3 | Итог тура **раскрывает** владельца, даже если было правило скрытности. |

## F. Пул правил

| ID | Решение |
|----|---------|
| F1 | Таблицу правил — **отдельным диалогом**. |
| F2 | Сверка «что было вживую» — отдельно. |
| F3 | Тур включения правил — после сборки полной таблицы. |
| F4 | Механика тяги правил — после того как увидим размер колоды. |

## G. Комнаты и боты

| ID | Решение |
|----|---------|
| G1 | Песочница — фиксированный формат + боты; рейтинговые — матчмейкинг (Fortnite-like: новая комната при заполнении 24, таймаут регистрации 2–3 мин). |
| G2 | **Застолье:** мин. **2** живых игрока. **Песочница:** 1→6 (5 ботов), 2→12 (10), 3→18 (15), 4→24 (20), 5+ — меньше ботов. |
| G3 | Типы ботов — см. [`11-bot-profiles.md`](11-bot-profiles.md). |
| G4 | Комната друзей: с ботами / без, старт по кнопке инициатора. Песочница: регистрация 1/3/5 мин → старт по таймеру. Рейтинговые/праздничные — позже. |

| ID | Решение |

## I. Контент

| ID | Решение |
|----|---------|
| I1 | Карты по **сезонам/коллабам**; **лайки** на картах (в руке / на стенде / после тура). ~**200** картинок на игру, ~**30** ситуаций; рейтинг карт по лайкам. |
| I2 | Тесты: текстовые карточки (ситуация + словесное описание картинки, напр. «метро»). |
