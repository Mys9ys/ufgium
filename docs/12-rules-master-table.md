## Как читать таблицу

| Колонка | Значение |
|---------|----------|
| **id** | Стабильный код для кода и карточек |
| **тип** | `base` — всегда в катке · `card` — карточка из пула · `meta` — как работает пул · `ban` — запрет · `session` — конец игры/профиль · `mode` — режим комнаты |
| **статус** | `ok` — согласовано · `draft` — черновик · `TBD` — ждём тебя |
| **было_вживую** | ✅ было на первой игре · ❌ не было · ? не помнишь · — не карточка |
| **с_тура** | С какого тура действует (`1`, `2`, `card`) |
| **текст_для_игрока** | Что показываем на карточке / в UI (черновик) |
| **эффект** | Машиночитаемая суть |
| **отменяет** | id правил, которые это гасит |
| **источник** | Откуда взяли |
