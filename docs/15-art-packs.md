# Арт-пачки UFG-1 (v0.2)

Урок из первой волны: **нельзя** рисовать один и тот же сюжет в трёх стилях — стол читает «один сет».  
Как у дополнений Imaginarium у фанатов: каждая пачка = **свой характер** (Pandora светлее, Persephone созерцательнее, Chimera темнее и т.д.), а не рескин.

| id | Название | Характер |
|----|----------|----------|
| `ink-yard` | **Чернильный Ярд** | бумажный сюр, классическая ассоциативная колода |
| `blue-dossier` | **Синее досье** | нуар DSSD, архив, долг, ночь |
| `balcony-tales` | **Балконные сказки** | тёплая мемология, туса, неловкость |

Каталог: [`../data/packs.json`](../data/packs.json)  
Картинки: `d:\OSPanel\home\ufgium.loc\assets\packs\{pack}\`

## Порядок работы

1. Утверждаем **16 сюжетов** одной колоды  
2. Генерим / дорисовываем только её  
3. Смотрим → следующая колода  
4. Сюжеты 17–96 — после стабилизации первых 16

## UX ставок на карточке

На стенде карточка держит ставку поверх арта:

| Слой | Как |
|------|-----|
| **Монеты** | Куча на картинке (pile) |
| **Аватары** | Открытый: кругляши кто поставил. Закрытый (`rule_hide_owners`): без имён до settle |
| **Overflow** | С 3+: два кругляша + бейдж `+N` |

Выбор колоды — при создании катки. Раздача и банк карт — из выбранного `pack_id`.
